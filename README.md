# 📊 Transactions Analytical Dashboard (Excel)

This project is an analytical dashboard built using **Microsoft Excel & Pivot Tables** to analyze transaction data and generate business insights.

---

## 🎯 Objective
Provide a clear overview of transaction performance, customer activity, and channel usage to support data-driven decision-making.

---

## 📊 Dashboard Overview

The dashboard includes:

- **Total Accounts**
- **Total Transactions**
- **Total Net Amount**
- **Average Transaction Value**

---

## 📈 Analysis Covered

- **Transactions Over Time (Trend)**
- **Top Customers**
- **Most Used Channel (ATM, Branch, Mobile, Online)**
- **Transactions by City**
- **Transactions by Time Bucket (Morning, Afternoon, Evening, Night)**

---

## 🎛 Filters

- Year
- Month
- City

---

## 🛠 Tools Used

- Microsoft Excel  
- Pivot Tables  
- Pivot Charts  
- Slicers  

---

## 💡 Key Insights

- ATM is the most used transaction channel  
- Transaction activity varies by time of day  
- Certain cities generate higher transaction volumes  
- Top customers contribute significantly to total transactions  

---

## 🚀 Outcome
The dashboard enables quick performance tracking and helps identify trends, customer behavior, and operational opportunities.
